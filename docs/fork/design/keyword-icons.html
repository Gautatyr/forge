Forge keyword icons

Every keyword icon the new match screen will draw on permanents, from the Mana font's Arena ability set. Each tile shows the icon large, then at its real size on a card: printed by the card, then added by another card.

Generic icons

Every other battlefield keyword uses one of these two, so the set stays consistent. Giving a keyword its own icon later is a one-line change.

Capacité statique

Stands in for battlefield keywords without their own icon, such as protection, shroud or infect. Hovering names the keyword.

ms-ability-static

Other triggered keyword

Capacité déclenchée

Stands in for keywords that trigger, such as annihilator or bushido. Hovering names the keyword.

ms-ability-triggered

No icon on purpose

Keywords that only matter off the battlefield or when casting: flash, cycling, kicker, flashback, cascade, convoke, and enchant/equip. The inspector still lists them in words.
